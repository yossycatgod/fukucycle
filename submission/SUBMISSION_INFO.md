# fukucycle — 提出情報

## プロダクト概要

fukucycleは、都市鉱山を「探す・回収する・学ぶ」体験へ変える位置情報Webアプリです。現在地から回収場までの方向と距離をマーカー上で確認し、1日1回チェックインできます。地域の利用者は回収場と学習コラムを追加し、同じサーバーへ接続したユーザー同士で共有できます。

## 推奨デモ手順

1. 審査用アカウントでログイン
2. 位置情報を許可
3. 地図マーカー上の方向矢印・方角・距離を確認
4. 最寄りの回収場を開き、経路・共有・デイリーチェックインを確認
5. 「素材ラボ」で電子機器に含まれる貴金属量を比較
6. 「学ぶ」で都市鉱山の基礎とユーザー投稿コラムを確認
7. 新しい回収場またはコラムを投稿し、別端末へ同期されることを確認

## 技術構成

- Python 3 / Flet
- OpenStreetMap タイル
- Nominatim 住所検索
- Flet WebSocketセッション
- PBKDF2によるパスワードハッシュ
- Cloudflare Tunnel（試験公開時）
